# Portfolio profesional — Walter Palacín

Primera versión de un portfolio construido con Next.js 15, React 19, TypeScript y CSS.

## Requisitos
- Node.js LTS (recomendado: 22 o superior)
- npm

## Ejecutar en Windows

1. Descomprime el ZIP.
2. Abre la carpeta `walter-portfolio` en Visual Studio Code.
3. Abre **Terminal > New Terminal**.
4. Ejecuta:

```powershell
npm install
npm run dev
```

5. Abre http://localhost:3000 en el navegador.

## Comprobar el proyecto

```powershell
npm run build
npm run lint
```

## Archivos principales
- `src/app/page.tsx`: contenido y componentes de la página.
- `src/app/globals.css`: diseño y adaptación a móviles.
- `src/app/layout.tsx`: estructura HTML y metadatos.
- `package.json`: dependencias y comandos.
